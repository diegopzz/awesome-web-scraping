# Contributing to Awesome Web Scraping

Thanks for helping keep this list useful.

## What belongs here

- Tools, libraries, platforms, and guides that people actually use for **legitimate** public-data collection.
- Items with a clear homepage or repository and a one-line reason they are on the list.
- Updates that fix dead links or replace abandoned projects with the current default.

## What does not belong

- Closed "secret" bypass kits, credential stuffing, or anything whose main purpose is account takeover.
- Duplicate entries already covered under another heading.
- Unmaintained projects with no commit in years, unless they are historically important and marked as such.
- Walls of affiliate links.

## Format

```markdown
- [Project](https://example.com) — Short reason it is useful.
```

- Description starts with a capital letter and ends with a period.
- Place the entry in the existing section that fits best. Alphabetical within a section when it is not harmful.
- Do not add a new top-level heading unless the topic cannot live anywhere else.

## Pull request checklist

- [ ] I personally used the tool or can point to why it is widely recommended.
- [ ] Link resolves and is not a tracking redirect.
- [ ] Description is one sentence, not a press release.
- [ ] I read the [Code of Conduct](https://www.contributor-covenant.org/) spirit: be decent.

## Legal note

Do not contribute step-by-step instructions for breaking access controls, defeating CAPTCHAs on a named target, or scraping personal data at scale. High-level tool names are fine. Target-specific evasion is not.
